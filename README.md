This project is a Python-based sports analytics tool that identifies potential NBA breakout players by comparing statistical performance across the current and previous season. Player statistics are retrieved from Basketball-Reference using Python, processed with Pandas, and analyzed using NumPy to evaluate year-over-year performance improvements and identify breakout players based on a scoring model.
